+--------------------------------------+----------------------------------------------+-------------------------------+---------------------------------------------------------------------------------------------+
| EY Application                       | Model Type                                   | Primary Metric                | Why This Metric?                                                                           |
+--------------------------------------+----------------------------------------------+-------------------------------+---------------------------------------------------------------------------------------------+
| Anomaly detection in invoices        | Anomaly Detection (Unsupervised Learning)    | Precision                     | Too many false alarms waste auditor time; precision measures how many flagged invoices are |
|                                      |                                              |                               | truly anomalous.                                                                           |
+--------------------------------------+----------------------------------------------+-------------------------------+---------------------------------------------------------------------------------------------+
| Spam classification in audit emails  | Classification                               | F1-Score                      | Balances Precision and Recall because both missing spam and incorrectly marking valid      |
|                                      |                                              |                               | emails are costly.                                                                         |
+--------------------------------------+----------------------------------------------+-------------------------------+---------------------------------------------------------------------------------------------+
| Predicting deal close probability    | Regression (or Probability Prediction)       | RMSE (Root Mean Squared Error)| Measures how close predicted probabilities are to actual outcomes; penalizes large         |
|                                      |                                              |                               | prediction errors.                                                                         |
+--------------------------------------+----------------------------------------------+-------------------------------+---------------------------------------------------------------------------------------------+
| Summarising 100-page contracts       | Generative AI (LLM / NLP Summarization)      | ROUGE Score                   | Compares generated summary with reference summary and measures content coverage.           |
+--------------------------------------+----------------------------------------------+-------------------------------+---------------------------------------------------------------------------------------------+
| Translating audit reports            | Generative AI (Neural Machine Translation)   | BLEU Score                    | Standard metric for evaluating translation quality against human translations.             |
+--------------------------------------+----------------------------------------------+-------------------------------+---------------------------------------------------------------------------------------------+
| Flagging revenue forecasting errors  | Anomaly Detection / Time-Series Forecasting  | Recall                        | Missing a forecasting error can be very costly, so catching as many true errors as         |
|                                      |                                              |                               | possible is important.                                                                     |
+--------------------------------------+----------------------------------------------+-------------------------------+---------------------------------------------------------------------------------------------+
