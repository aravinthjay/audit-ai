SHOPIQ: PERSONALISED PRODUCT RECOMMENDATION EMAIL
=================================================

1. ARCHITECTURAL CHOICE: SINGLE AGENT
-------------------------------------
Based on the case constraints, a Single Agent architecture is the optimal choice due to:
- Shared User Context: The entire pipeline (fetching history, candidate generation, applying business rules, copywriting, and HTML assembly) relies on a single, unified user context object. Passing this seamlessly within a single execution scope avoids the serialization overhead of multi-agent handoffs.
- Strict Latency SLA (< 3s per user): A tight time window leaves no room for the communication, routing, and consensus coordination overhead intrinsic to multi-agent frameworks.
- Linear Batch Pipeline: The tasks follow a highly predictable, step-by-step linear flow suited for a deterministic execution pipeline or single routed agent rather than a dynamic team.

3. PIPELINE STAGE BREAKDOWN
---------------------------
- Stage 1 & 2 (Data Fetch & Recs): Traditional, fast database queries and embedding lookups that hydrate the user context.
- Stage 3 (Deterministic Logic): Standard hard-coded if/then business constraints filtering the top-10 list.
- Stage 4 (Generative Copywriting): A fast, highly-focused LLM call using the context to write a tailored intro snippet.
- Stage 5 (Assembly): A template rendering step combining the intro text and recommended product modules into HTML.
